description=Import and merging of provincial BDOO databases (GML, 1:250,000) from multiple provinces into a single output database (GeoPackage / GML / ESRI geodatabase / SQLite / GeoParquet). Version for QGIS 3.x (PyQt5). Import i scalanie wojewodzkich baz BDOO (GML, 1:250 000) z wielu wojewodztw do jednej bazy wynikowej (GeoPackage / GML / ESRI geobaza / SQLite / GeoParquet). Wersja dla QGIS 3.x (PyQt5).
version=1.0.0
author=Sławek Szymański
email=apka.tarcz@gmail.com

about=Instrukcja: w katalogu wejsciowym mają być pliki *.zip, katalog w srodku musi miec strukturę PL.PZGiK.201.02 (okresla wojewodztwo). Podpowiedzi pojawiają się po najechaniu na dany element interfejsu.
      Wtyczka importuje pliki BDOO (paczki .zip z danymi GML, wojewodztwo po wojewodztwie, zgodnymi ze schematem BDOT10k_BDOO.xsd) dla jednego lub wielu wojewodztw, scala warstwy tego samego typu w jedna wspolna tabele, automatycznie dostosowuje szerokosc pol tekstowych do najdluzszej wystepujacej wartosci, pozwala pominac obiekty z zamknietym cyklem zycia (pole koniecWersjiObiektu) i eksportuje wynik do dowolnej kombinacji formatow: GeoPackage, GeoParquet, GML, ESRI File Geodatabase (.gdb) i SQLite/SpatiaLite. Wymagane schematy XSD sa wbudowane we wtyczke - uzytkownik nie musi ich samodzielnie dostarczac. Kazdy plik zrodlowy jest raz konwertowany do lekkiego formatu posredniego (z cache na dysku) - kolejne importy tych samych danych sa znaczaco szybsze. Ta wersja jest przeznaczona wylacznie dla QGIS 3.x (PyQt5) - dla QGIS 4.x zainstaluj osobna wtyczke "Import BDOO (QGIS 4.x)".
